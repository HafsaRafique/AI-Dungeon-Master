# LoreCraftAI

LoreCraftAI is an AI-powered storytelling engine for a text-based RPG. Every action you take gets sent to an AI, which responds with structured JSON data, a story update, mood, theme, and visual description. The app reads that data and rebuilds the entire UI around it, creating a world that visually and narratively changes with every decision.
This is a fun side project to explore what happens when you use AI as a game engine rather than a chatbot. Instead of asking it questions, you give it actions and it returns a living, evolving world state. The long-term vision is a fully AI-driven interactive world where the story, visuals, and interface all shift in real time based on what the player does.
